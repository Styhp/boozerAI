## Code review

- The Host/Origin policy runs before API dispatch (`src/server/app.ts`). Every API route needs the 256-bit per-launch bearer token, compared with `timingSafeEqual`. POST also needs the exact Origin, a JSON content type, an 8 KB body cap and exact fields.
- The routes match a strict regex with no URL normalization. Files are reachable only through per-snapshot random IDs, and refresh renews them.
- The explanation `path` is checked only against snapshot entries and never touches the filesystem. Error bodies are fixed codes, and NDJSON errors are fixed strings. Both of my route conditions are met.
- One explanation at a time. Refresh and close abort running streams, and disconnects abort the model call. The route timeout is 120 s.
- The launcher uses `spawn(open | xdg-open, [url])` with no shell. Preload never blocks startup, and model unavailability never blocks indexing. There's no cloud fallback.

## Non-blocking notes

- **N1. The token in the launch URL.** The capability travels as a process argument to `open`/`xdg-open`, and the browser may record the launch URL, fragment included, before the client strips it. That's acceptable on a single-user machine: the token is per launch and revoked on close or exit. **For the video, start recording after the launch tab has loaded**, so the address bar never shows `#cap=…`.
- **N2. Reload ends the session**, because authority lives only in memory. Rehearse the demo without reloading. If it happens, restart the launcher.
- **N3. Route timeout 120 s vs adapter 180 s.** Answers took 16–65 s on the contended Mac. If MSI answers approach 120 s in M6, align the two timeouts.
- **N4. P-16 needs a small route change.** The explanation body rejects extra fields (correct today), so cloud's `provider` field requires Codex to extend `fields()` and the contract. That's Codex's file; Agent B proposes the contract.
- **N5. Port 4173 is fixed.** Stop stray `npm run dev` processes before the rehearsal.
